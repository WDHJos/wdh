How to Search

Search by author

Main author

Enter the first letters of the family name. The search returns all main authors whose family name begins with the entered letters.

Example: input Ott returns Ott, Otto, Ottens, Ottaviani, but not Scott.

Example: input Ot returns Ott, Otto, Ottens, Ottaviani, but not Scott.

All authors

Enter part of a family name or several names separated by semicolons (;). The search scans all author fields.

Example: input Ouweneel returns Ouweneel.

Example: input Ouwe may return Ouweneel, Boelhouwer, vanHouwen, and similar names.

Search by title

Enter one or more words from the title. The title search supports the following options:

SymbolMeaningExample
;OR filterhappiness; life satisfaction returns titles with either happiness or life satisfaction.
&AND filterhappiness & elderly returns only titles in which both terms occur.

Author and title searches can be combined.

Search by subject

The website provides a subject table with WDH standard subject descriptions and keywords.

Enter a keyword in the search field of the Subjects table. The corresponding subject will appear. If you then return to the Publications table, this table is automatically filtered based on the selected standard subjects.

Filter and sort publications

Publications can be filtered or sorted by the following classification columns:

  • Determinant
  • Consequence
  • Contentment
  • Overall Happiness
  • Hedonic Level
  • Contains Data

Sorting three columns at a time

All columns can be sorted by means of the arrow to the right of the header name. The first sort is indicated by number 1, the second by number 2, and the third by number 3.

Reset

All search and sort activities can be cleared with the reset button.
