Search This Website

What can be found

This website is a collection of publications as described on the About the Publications page. It can be searched by title, by main author or all authors, and by subjects. A combination of main author or all authors with title and subjects is possible.

For practical instructions, see How to Search.

All publications before and including 2020 can also be searched under Studies and Findings on the original World Database of Happiness website. Publications after 2020 are coded by subject, but no further studies have been conducted on them.

Search by subject

The six basic categories — Determinant, Consequence, Contentment, Overall, Hedonic, and Contains Data — can be used by sorting these columns on the Publications page to obtain a first selection of desired publications.

A more substantive selection can be performed by searching with the subject description.

To find a subject description, go to the Subjects page. This page contains the subject table with keywords. Use keyword searches to find possible subject descriptions.

In the table, the standard WDH subject description is shown together with the corresponding keywords. The subject descriptions themselves have also been added as keywords. In this way, you only need to search for keywords to find the subject description.
